# Финальный проект 6 спринта

## Описание
Проект содержит UI-автотесты для веб-приложения для 6 спринта яндекс практикума.

---

## Технологии

- Python 3.11.3
- Selenium WebDriver
- Pytest
- Allure Report
- Page Object Model (POM)

---

## Архитектура проекта

Проект построен по паттерну **Page Object Model**

```
SPRINT_6/
│
├── locators/ # Локаторы страниц
│ ├── common_locators.py
│ ├── main_page_locators.py
│ └── order_page_locators.py
│
├── pages/ # Page Object классы
│ ├── base_page.py
│ ├── main_page.py
│ └── order_page.py
│
├── tests/ # Тесты
│ ├── test_main_page.py
│ └── test_order_page.py
│
├── config.py # Константы (URL и т.п.)
├── conftest.py # Фикстуры pytest
├── helpers.py # Вспомогательные функции
├── pytest.ini # Настройки pytest
├── requirements.txt # Зависимости
└── README.md
```

---

## Реализованные сценарии

### Главная страница
- Проверка работы FAQ
- Проверка перехода по логотипу Самоката
- Проверка перехода по логотипу Яндекса (открытие новой вкладки)

### Позитивный сценарий оформления заказа
Проверяется:
- Обе точки входа (верхняя и нижняя кнопка "Заказать")
- Заполнение формы
- Появление модального окна успешного заказа
- Переходы по логотипам после оформления

Используется параметризация с двумя наборами данных.
